# Dalei TV Home

原创、以本地界面为主的电视附加应用。左侧少量大字菜单，焦点描边和轻微放大，右侧留给背景。不是系统桌面替换器，也不是 Sony 官方主题。

## 功能

- 上下方向、确认、返回；长列表五行滚动、位置提示和边界限制。
- 返回上一级恢复选中项及滚动位置；按组件标识恢复，应用增删后安全回退。
- 长中文名称使用标准省略算法，给省略号和屏幕边缘留出空间。
- 应用入口来自系统已安装、启用且可公开启动的 Activity；不硬编码某台电视的应用。
- 首页提供通用视频快捷入口：用户在本机选择应用，选择只保存偏好，不自动启动或播放。之后手动点击才通过标准 Intent 打开；失效时回退应用列表。
- 默认使用程序绘制的通用背景，没有私人照片。可在本地构建覆盖壁纸，覆盖文件被 Git 忽略。

仅申请INTERNET以读取用户明确配置的单一只读统计JSON；不申请外部存储或无障碍权限，无统计上报、后台服务、自启或HOME声明。只在应用私有本地偏好中保存视频组件、动效偏好和最后成功统计快照，不上传或同步。

## 兼容与验证范围

最低 API21，targetSDK28，包名 `io.github.paul010.daleitvhome`，版本0.5.1。本版是面向手动侧载的实验，不宣称符合当前应用商店政策。

公开0.5版仅完成编译、清单/DEX/资源静态检查和纯Java导航测试；没有部署到电视或完成视觉验收。旧私人原型的真机结果不能当作本版验证。实体遥控、第三方应用切换返回、特殊屏幕比例、长期性能和完整读屏可访问性尚待测试。

HDMI、3D厂商控制、自动播放、嵌入内容流、账号、播放操作和刷机均未实现。没有包含第三方播放器代码或APK，也不担保用户选中的播放器版本安全。播放器的问题与本桌面分开核验。

## 构建

已有JDK（实测21）、SDK Platform21、Build-Tools35.0.0、Bash和Python3即可，不需要Gradle。工具与许可证由使用者从官方来源另行准备；本仓库不自动下载或接受协议。

```sh
export JAVA_HOME=/path/to/jdk
export ANDROID_HOME=/path/to/android-sdk
bash test.sh
bash build.sh
python3 verify.py output/dalei-tvhome-0.5.1-unsigned.apk --public
```

输出为未签名APK。构建不会生成密钥、安装应用或修改设备。审核后自行签名，API21需保留v1签名，再明确手动侧载；保持原系统桌面，首页按返回可退出。

## 私人壁纸

把有使用权的图片放到 `assets/local-wallpaper.png`，本地重新构建。该文件被Git忽略，但会嵌入自己的APK，勿公开含私人照片的APK。公开版检查 `--public` 会拒绝带图片的产物；检查私人覆盖构建时省略该参数。删除覆盖图片并重建即可恢复程序背景。不读取电视相册或系统壁纸。

## 0.5 原生统计

APK原生绘制额度条、数字和14日期趋势，不嵌入看板截图，也不OCR。私有构建可在被Git忽略的 `assets/local-dashboard.properties` 设置 `jsonUrl=`：仅支持用户批准主机的8787端口和精确 `/api/tv-codex` 路径。公开版没有地址。只在工作台可见且应用在前台时每60秒请求，离开即停止。32KiB上限、禁重定向、连接/读各4秒及12秒总超时。

纯函数 `adapters/memory-snapshot.mjs` 只对白名单内存对象做转换，不采集、不读文件、不执行RPC。部署者必须先授权已有服务的只读路由，以真实socket来源IP和Host限制访问，不采用X-Forwarded-For、不加通配CORS或新监听。IP限制不是身份认证，HTTP未加密。

源采样时间与响应/获取时间分开；超过120秒显示过期，上游事件时效并未独立验证。跨过重置时刻即不再显示有效额度。每日统计日界未知，因此今日保持null；累计明确为累计，14日期趋势不当作30天，缺失不等于零。失败保留上次成功快照并标注。详见 [数据边界](docs/native-codex-memory-plan.md)。

私人壁纸 `wallpaper-01.png` 等只在首页轮换，离开暂停，设置可静止；透明 `local-portraits.png` 左右半区分开绘制，每人约画面高度22%，不与背景大人物重复。公开版不含照片、生成图、实际数据或设备地址。
