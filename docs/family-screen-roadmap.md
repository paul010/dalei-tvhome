# Family screen roadmap (planned)

Current scope is household screen presentation, not connected home-device control. Future optional local role model: id, displayName, type(owner|pet), localAssetRef, animationProfile, visibility. Portraits are not authentication identities. Keep photos and derivatives in ignored local overlays; public code only contains generic models/rendering. Default motion should be subtle, localized and pausable, with reduced-motion support. Do not obscure faces or navigation.

Role editing, private pet assets, live usage data, content feeds, speech and authenticated control bridges remain separate milestones. No hub device connection, token provisioning, background service or home automation is implemented or authorized by this roadmap.
